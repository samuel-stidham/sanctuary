Safetybox <VERSION>

Safetybox is a CLI-first secrets manager. Values are sealed in age envelopes. Metadata lives in SQLite.

Usage:
  safetybox [command]

Available Commands:
  completion  Generate the autocompletion script for the specified shell
  delete      Soft-delete a secret
  disable     Disable a secret version
  exec        Run a command with secrets injected into its environment
  get         Fetch and verify the newest enabled version of a secret
  help        Help about any command
  init        Create a new identity and vault
  list        List secrets, optionally under a name prefix
  migrate     Upgrade an older vault to the current format
  passwd      Change the identity passphrase
  purge       Destroy a secret's envelopes forever
  rekey       Rotate the identity and re-encrypt every live version
  reveal      Deliberately print secrets' plaintext values
  set         Store a new version of a secret
  show        Print a secret's metadata, never its value
  stale       List secrets past their expiry

Flags:
  -h, --help[=true|false]        help for safetybox
      --identity string          path to the identity file (default $XDG_CONFIG_HOME/safetybox/identity.age)
      --json[=true|false]        emit compact JSON for pipes instead of pretty JSON
      --log-json[=true|false]    emit logs as JSON
      --passphrase-file string   read the identity passphrase from this file instead of prompting
      --vault string             path to the vault database (default $XDG_DATA_HOME/safetybox/vault.db)
  -v, --verbose[=true|false]     enable debug logging
      --version[=true|false]     version for safetybox

Use "safetybox [command] --help" for more information about a command.
