set reads the value from stdin, or from a no-echo prompt on a terminal, and appends it as a new enabled version. Values never come from arguments. Prior versions stay enabled unless --revoke-previous is passed.

Usage:
  safetybox set <name> [flags]

Flags:
      --env-name string                environment variable name used by exec
      --expires string                 expiry as RFC3339 or YYYY-MM-DD (staleness flag, never deletion)
  -h, --help[=true|false]              help for set
      --revoke-previous[=true|false]   disable all older enabled versions

Global Flags:
      --identity string          path to the identity file (default $XDG_CONFIG_HOME/safetybox/identity.age)
      --json[=true|false]        emit compact JSON for pipes instead of pretty JSON
      --log-json[=true|false]    emit logs as JSON
      --passphrase-file string   read the identity passphrase from this file instead of prompting
      --vault string             path to the vault database (default $XDG_DATA_HOME/safetybox/vault.db)
  -v, --verbose[=true|false]     enable debug logging
