set reads the value from stdin, or from a no-echo prompt on a terminal, and appends it as a new enabled version. Values never come from arguments. Prior versions stay enabled unless --revoke-previous is passed.

  [32m-h, --help[=true|false][0m              help for set
      [32m--revoke-previous[=true|false][0m   disable all older enabled versions
